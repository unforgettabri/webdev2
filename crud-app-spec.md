# Book Library CRUD Application

## Project Description

The Book Library is a simple web application for managing a collection of books. Users can add, view, edit, and delete book records through a web interface.

## Functional Requirements

- REQ-1: The system shall allow users to add a new book with its title, author, genre, and publication year.
- REQ-2: The system shall display a list of all books currently stored in the system.
- REQ-3: The system shall allow users to edit the details of an existing book.
- REQ-4: The system shall allow users to delete an existing book from the system.
