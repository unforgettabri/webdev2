# Webdev2 - Week 2

## Spring Boot Shop Application

This project is a Spring Boot application created for Week 2.

### Features
- Product model with name and price
- In-memory ProductRepository
- ProductService with price filtering
- Constructor dependency injection
- Shop configuration using `application.properties`
- Startup shop report using CommandLineRunner

### Configuration
- Port: 8082
- Shop Name: My Web Store
- Currency: PHP

### Run
```bash
./mvnw spring-boot:run
